# 旧行为基线刻画

在修改预期行为不完整、文档不足的遗留逻辑前，使用本技能捕获旧行为基线。

## 输入

- 活跃入口地图。
- 现有输入样例或近似生产数据抽样。
- 现有输出文件或可运行的旧命令。
- 已知下游输出契约。

## 执行步骤

1. 选择最小但有代表性的输入，覆盖当前已支持的行为。
2. 尽可能在不修改旧代码的情况下运行旧路径，捕获基准输出。
3. 如果旧路径无法运行，可以从历史输出中重建预期行为，但必须明确标记为“推断”。
4. 为兼容性关键文件添加特征测试，做精确输出对比。
5. 区分两类行为：短期必须保留的历史偶然行为，以及可在功能开关下有意改变的行为。

## 输出格式

输出内容包括：

- 基准输入文件。
- 基准输出文件。
- 特征测试用例。
- 必须保留的旧行为列表。
- 需要审批的有意变更候选项。

## 验收标准

- 当字段顺序、精度、排序或空值格式发生非预期变化时，特征测试必须失败。
- 基准输出来自未修改的旧路径，或被明确标记为推断产物。
- 在兼容性关键基线建立前，不进入新功能实现；若无法建立，必须将其作为风险例外记录。
