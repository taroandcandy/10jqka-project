# 安全重构切片

当遗留脚本需要新增能力，但大范围重写会带来兼容性风险时，使用本技能。

## 输入

- 入口地图。
- 旧行为基线。
- 新需求。
- 兼容性契约。

## 执行步骤

1. 区分纯重构和行为变更。
2. 优先做无行为变化的抽取：把解析、计算和输出写入封装到函数后面，但不改变可观察输出。
3. 每次抽取后先补测试，再进入下一步变化。
4. 新行为通过功能开关或新命令选项引入。
5. 新结构契约和聚合结果优先采用新增输出，而不是直接替换旧输出。
6. 在灰度发布通过前保留旧入口路径，让回滚足够简单。

## 建议切片

- 抽取 CSV 读取器，不改变输出。
- 抽取移动平均线计算器，并通过基准文件一致性验证。
- 抽取输出写入器，精确保留旧结构契约。
- 在新选项后面增加多股票分组。
- 增加脏数据诊断，但不改变旧输出。
- 将行业聚合作为新输出文件增加。
- 增加兼容适配层和发布开关。

## 输出格式

输出一份有序实现计划，包含：

- 切片名称。
- 可能涉及的文件。
- 属于行为变更还是无行为变化重构。
- 所需测试。
- 回滚影响。
- 审查重点。

## 验收标准

- 除非明确说明理由，不允许一个切片同时包含大结构调整和用户可见行为变化。
- 每个切片都有窄范围测试目标。
- 发布完成前旧路径仍然可调用。
